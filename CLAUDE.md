# Orwell monorepo — agent guide

**The guide lives in [`AGENTS.md`](AGENTS.md). Read that.**

This file is a pointer, deliberately. It used to hold the guide itself; keeping a second copy here
would be the same mistake the repo unwinds elsewhere — two descriptions of one thing, drifting apart
the first time somebody edits one of them. `AGENTS.md` is the vendor-neutral name every agent tool
now looks for, so it is the one that gets maintained.

Add nothing below this line. New conventions go in `AGENTS.md`, new defects in
[`ISSUES.md`](ISSUES.md), new debt in [`CODE_REFACTOR.md`](CODE_REFACTOR.md).
